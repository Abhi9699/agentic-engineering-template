# Conventions

Hub index: [[_START-HERE]].

- **Code Style:** TypeScript strict mode, no `any`, modular functions <= 400 lines.
- **Security:** Zero-trust backend actions, `crypto.timingSafeEqual()` for tokens.
- **A11y:** WCAG 2.2 AA compliant markup with programmatic labels and visible focus rings.
- **Testing:** Every defect fixed must be paired with an automated regression test.
