# Glossary

Hub index: [[_START-HERE]].

- **Spine:** The tool-agnostic AGENTS.md single source of truth.
- **Gate:** An automated command that checks code quality, security, and tests before commit or push.
- **Executive Review:** Multi-lens risk assessment (CTO, CPO, CISO, Legal, CFO) executing pre-mortems before non-trivial changes.
- **Lessons Ledger:** Machine-enforced anti-regression catalog in `vault/_Lessons.md`.
